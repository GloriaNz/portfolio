# Portfolio Professionnel — Gloria Nziengi Kimbila

Portfolio moderne, interactif et bilingue (Français / Anglais) de Gloria NZIENGI KIMBILA — Développeuse Backend (Python/Flask) & Intégration API / IA.

## 🚀 Fonctionnalités
- 🌐 **100% Bilingue (FR / EN)** avec bascule instantanée sans rechargement.
- ⚡ **Animations dynamiques** : effet dactylographie, défilement fluide, apparition progressive au scroll, particules d'arrière-plan.
- 📄 **Téléchargement direct du CV en PDF** et visualisation en ligne.
- 💬 **Liaisons directes** : WhatsApp direct, Email, LinkedIn, GitHub.
- 📱 **Design responsive** adapté aux mobiles, tablettes et ordinateurs.

## 🛠️ Technologies
- HTML5 sémantique
- CSS3 moderne (Variables, Flexbox, CSS Grid, Glassmorphism, Micro-animations)
- JavaScript Vanilla ES6+ (i18n dynamique, IntersectionObserver)
- Font Awesome 6 & Google Fonts (Inter, JetBrains Mono)

## 📦 Structure du projet
```
├── index.html              # Structure et contenu du portfolio
├── styles.css              # Feuille de styles et design
├── script.js               # Animations, typing effect et logique
├── translations.js         # Dictionnaire complet de traduction FR / EN
├── gloria-profile.jpg      # Photo de profil officielle

```
